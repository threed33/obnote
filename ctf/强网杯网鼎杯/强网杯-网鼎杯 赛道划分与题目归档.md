# 强网杯 & 网鼎杯：赛道划分与题目归档

> 整理时间：2026-09-20
> 数据来源：赛事官网、高校通知、CTF-Archives 归档仓库

## 一、强网杯（第九届，2025年）

### 1.1 赛道划分

第九届强网杯共设 **4 个大板块**，赛道数量比往届明显扩容。

| 板块 | 定位 | 参赛要求 |
|---|---|---|
| **线上赛** | 面向国内高校、企业、机构等网络安全力量 | 每队 ≤10 名队员 + 1 名指导教师（领队） |
| **线下赛** | 按线上赛排名选取 **32 支**队伍 | 每队 ≤4 名队员 + 1 名指导教师（领队） |
| **行业领域专项赛** | 面向国家战略需求和产业布局，设 **3 个赛道** | 每队限 6 人（含队长 1 名），可另有领队/指导老师 1 名；同一赛队只能选 1 个科目，单位可组织多队 |
| **创新创业专项赛** | 提交创新网络安全解决方案，做产业孵化 | 每队限 6 人（含队长 1 名），另有领队 1 名、指导老师 2 名（不占名额）；每人只能担任 1 个作品负责人 |

**时间安排：**
- 线上赛：10月18日–19日（报名截止 10月17日 17:00）
- 线下赛：11月22日–23日
- 行业领域专项赛 / 创新创业专项赛：2025年9月–11月

### 1.2 行业领域专项赛的 3 个赛道

1. **漏洞智能分析与识别**
2. **天基互联网安全**（国内首次设立，46 支队伍报名，15 支进线下）
3. **车联网安全**

> 天基互联网安全赛道现场模拟真实星务测控场景，要求通过上注遥控指令完成"打开在轨离线数据开关""星上授时设置""操控飞轮改变整星姿态"等高难度任务。

### 1.3 赛题方向（重点）

**线上赛**（偏综合知识与基本实践技能）：
- 二进制程序逆向分析
- 密码分析
- 智能终端安全
- 信息隐藏
- 人工智能

**线下赛**（偏创新实践能力）：
- 二进制程序漏洞挖掘与分析
- Web 应用漏洞挖掘与分析
- 设备固件漏洞挖掘与分析
- 物联网设备安全测试
- 人工智能在网络安全领域的赋能应用

### 1.4 线上赛题目实例（2025 qwbs9）

按 CTF 分类列出实际赛题（共 40 余题）：

| 分类 | 题目 |
|---|---|
| **Misc** | 签到、谍影重重 6.0、Personal Vault、The_Interrogation_Room、Qcalc、legacyOLED、cpc、Secured Personal Vault、BlackPearl、问卷调查 |
| **Crypto** | Blurred、theorezhnp、sk、check-little、ezran |
| **Reverse** | PolyEncryption、tradre、ABabyChal、butterfly、iked |
| **Pwn** | adventure、babyjs、babybus、flag-market、sockserver、bph、go2php、tradpwn、file-system、ez-stack |
| **Web** | PTer、SecretVault、ezphp、CeleRace、anime、bbjv、yamcs、日志系统 |

**几个值得注意的点：**
- `Qcalc` 是 **Android 漏洞利用题**，要求编写 exploit APK
- `yamcs` 基于真实开源项目 YAMCS 源码做审计，通过 `AlgorithmText` 实现算法注入
- `PolyEncryption` 是多语言加密（C#/Java/Python 三层），有人用 AI 辅助完成逆向
- 官方明确 **允许使用生成式 AI 辅助解题**，但需保留完整 AI 对话记录并上传网盘，writeup 开头附链接

## 二、网鼎杯（第四届，2024年）

### 2.1 赛道划分：按**行业属性**分四个赛道

这是网鼎杯和强网杯最大的区别 —— **网鼎杯按参赛者所属行业分赛道**，而不是按技术方向分。

| 赛道 | 覆盖范围 |
|---|---|
| **青龙组** | 高等院校、职业院校 |
| **白虎组** | 通信行业、交通、金融、医疗卫生、政法及政务部门 |
| **朱雀组** | 能源电力、化工、国防及其他行业 |
| **玄武组** | 科研机构、科技企业、网安企业、互联网企业及社会参赛队伍 |

**赛段划分（三赛段）：**
1. **官方资格赛**（2024年10月29日–11月4日，线上）—— 采用 CTF 夺旗赛制，每场 8 小时
2. **半决赛**（2024年11月下旬，贵阳）—— 600 支战队、约 2400 人晋级
3. **总决赛** —— 60 支队伍、240 人

**规模：** 21804 支队伍、40401 名选手参加线上资格赛（官方通报数据）；媒体报道超 3 万支队伍、近 7 万人报名，为同类赛事规模之最。

### 2.2 赛题类型

覆盖 **人工智能、车联网、物联网、5G** 等前沿应用：
- **夺旗赛（CTF）**：提炼典型安全风险漏洞相关的技术点和应用环境
- **综合防御赛**：安全流程完善、漏洞挖掘、代码审计及修复
- **靶场渗透赛**：模拟真实业务场景，考查信息收集、漏洞挖掘和利用能力

### 2.3 半决赛题目结构（第四届）

半决赛分 **专项技术挑战赛** 和 **安全运营挑战赛** 两块，专项赛按 5 个方向组织：

| 方向 | 题目 |
|---|---|
| **二进制安全** | `cardmaster`（二进制漏洞挖掘）、`Generic_kernel_shellcode`（系统内核漏洞挖掘）、`jitlover`（新编译技术漏洞 / 不完全 JIT 虚拟机） |
| **密码学** | `equations`（RSA 加密分析）、`noise`（序列密码加密分析 / noisy-nfsr） |
| **数据安全** | `Easy_Data`（邮件数据分析 / DLP 告警）、`Never Finish`（自定义 TLS 协议，AES CFB 模式伪造签名消息） |
| **新技术应用** | `V2XLogAnalysis`（车联网日志分析）、`signin`（IOT 应用容器漏洞）、`babyRTP`（IOT 网络协议分析）、`Get_supi`（5G 网络隐私保护） |
| **逆向安全** | `compress`（Python 逆向）、`socket`（网络通信流量分析） |

### 2.4 初赛题目特点（分组略有差异）

**青龙组**（高校）：
- Crypto：神秘代码解密、AES 密钥寻找
- Misc：流量取证定位信息泄漏、计算机异常变慢排查
- Web：RS256 弱公钥 JWT 伪造 + Flask session 伪造 + XXE 通过 UTF-16 绕过黑名单任意文件读取
- Reverse：Android 应用逆向（SM4 加密）
- Pwn：菜单程序安全测试

**白虎组**（通信/金融/政务）：
- Misc 涉 **5G 流量分析**（找攻击者构造的 teid 拼接成 flag）
- 通信运营商攻击流量分析
- Crypto 涉及量子计算概念题、矩阵/置换密码

**朱雀组**（能源/国防等）：
- Crypto：RSA 部分素数高位泄漏攻击
- Misc：卫星数据解密、盲盒抽奖程序（JDK 1.8）、文件隐藏与磁盘加密

**Flag 格式：** `wdflag{xxxxx}`

## 三、两个赛事的对比

| 维度 | 强网杯 | 网鼎杯 |
|---|---|---|
| **举办周期** | 每年一届（2015年创办） | 两年一届（2018年创办） |
| **指导单位** | 中央网信办、河南省人民政府 | 公安部、教育部 |
| **赛道划分逻辑** | 按**赛段+技术方向**（线上/线下/行业专项/创新创业） | 按**行业属性**（青龙/白虎/朱雀/玄武） |
| **特色方向** | 天基互联网安全、车联网安全、AI 赋能 | AI、车联网、物联网、5G、数据安全 |
| **线上赛制** | Jeopardy（解题）为主 | CTF 夺旗赛，4 组分组开赛 |
| **线下赛制** | Real World + AWDU 混合 | 综合防御赛 + 靶场渗透赛 |
| **规模** | 3018 支战队、1.3 万人（第九届） | 超 3 万支队伍、近 7 万人（第四届） |
| **奖金** | 500 万元量级 | 68 万元 |
| **举办地** | 郑州（2020年起永久落地高新区） | 贵阳（第四届） |
| **题目归档** | CTF-Archives（qwbs 系列） | CTF-Archives（wdb 系列） |

## 五、几点观察（给备考参考）

1. **网鼎杯按行业分组，对高校学生来说青龙组就是主战场**，且明确不允许教师和学生混合组队代表院校 —— 高校队伍必须全为本校学生，跨校组队只能算"社会参赛队伍"（归玄武组）。强网杯没有这个限制。

2. **两个赛事的难度定位不同**：强网杯线上赛是标准的 CTF 解题赛（Jeopardy），门槛相对可控，适合作为主攻目标；网鼎杯线下赛以综合防御 + 靶场渗透为主，更偏企业级实战。

3. **AI 辅助解题已被官方认可**。第九届强网杯参赛须知明确允许使用生成式 AI，只需保留对话记录并附在 writeup 里。这个变化值得注意。

4. **刷题建议路线**：先用 CTF-Archives 的 `2025-qwbs9-quals` 热身（Web + Misc 方向题目质量高、贴近真实场景），再看 `2024-wdb-qinglong` 熟悉网鼎杯高校组风格，最后啃半决赛的 `2024-wdb-Semis-CTF`（数据安全、车联网、5G 这些方向是网鼎杯特色，别的地方练不到）。
